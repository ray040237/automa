header 的四个决定

底色 bg-surface → bg-canvas。 参考 TopBar.tsx:29（bg-canvas + border-b border-line）。 收益：header 与 composer 都回到 canvas，「夹在中间的内容」是唯一浮起的东西， 层级从「三段并列」变成「一条底 + 中间卡片」。
行数 两行（已拍板）。参考 TopBar.tsx:33-46 的两行结构。 行 1 = 图标 + 可点的标题 + 新建； 行 2 = 标签页切换（整行宽的 chip）。
会话入口 从「宽 chip 带底色」改成 28px 图标按钮 + 可点的标题。 理由：现状那个 bg-box-transparent 灰胶囊占了大半行， 却只表达「点这里进历史」；参考实现用 28px 图标按钮做同一件事 （IconButton.tsx 的 sm: h-7 w-7）， 标题因此能多显示 3~4 个字。 标题本身是一个下拉触发器（见下一条）。
标题即下拉 本次改动的核心。点标题就地弹出会话列表：切换（点一行即切）、 删除（每行右侧垃圾桶，hover 才显形）、底部一行「查看全部历史会话」 导向正文区的整页历史视图。 这样「会话管理」不再需要单独一行 —— 省掉一整行， 而「切换」这个最高频动作从「跳到另一屏」变成「就地在原地」。 列表复用 AgentSessionList 已有的两行密度与分组逻辑。
模型状态 不放 header，放 composer 底行。参考实现就是这么分的 （ModelPicker 在 Chat.tsx:2140 的底行里）。 理由：模型是「这一句话用谁答」，与发送动作同一决策时刻； 而 header 表达的是「我在哪、看什么」。 这一条与 T-201 合并处理。

2.2 输入区：卡片与输入框谁凸谁凹

这里有个方向性错误值得单说。参考实现是 bg-field 卡片 + 内部 bg-transparent 的 textarea —— 卡片整体是一块「凹」下去的区域，字写在凹陷里。 而 Automa 现在是 bg-surface 卡片（凸）+ !bg-field textarea（凹），变成凸的里面挖了个凹的， 320px 宽下看起来像「一张白纸上贴了一张灰纸条」。

2.4 标签页这一行的美化

原稿这一行只是一条「无底色的文字 + favicon」（像一段说明文字，看不出可点）。 既然它是这一行唯一的东西、又是唯一入口，就该有明确的控件外观。 下面三种状态可切换查看。

标签页 chip 的三种状态已美化

① 已固定：实心 chip（surface + line 边），favicon + 完整标题 + 已固定 徽标 + 箭头。
② 自动：无边框、fg-2 文字，hover 才浮出底色 —— 不抢注意力。

图标 用项目现成图标：自动态走 riFlashlightLine（闪念/跟随）， 失效态走 riErrorWarningLine。均为 v-remixicon， 不引入任何新依赖。
hover / active hover 时描边转 fg-3（比底色变化更清楚「这是个盒子」）； active 时底色转 field。均走 ease-panel 140ms。

§7 落地步骤（可独立验收的 6 步）

  1. 删 --color-shell（tailwind.css 两处 + tailwind.config.js 的 colors.shell + host.shell + AgentPanel 的 shell computed + sidepanel/App.vue 的 bg-shell）， 面板根回到 bg-canvas。同时把 T-212 的守卫 ①⑥⑦ 改成 「面板根是 bg-canvas」单条断言。 → 独立可验收，风险最低，建议先做。
  2. header 降层 + 拆两行：bg-surface → bg-canvas； 会话 chip 换成 28px 图标按钮 + 可点的标题（标题 = 会话下拉触发器， 内含切换 / 删除）；第 2 行放美化后的 AgentTabPicker（整行宽 chip）。 → 此时页面来源在 header 和卡片里各有一份，属临时双写。
  3. composer 底行重排：补 <div class="flex-1" />； 发送键从 ui-button h-10 收到 32px； composer 顶部提示行删掉（内容改挂发送键 title）。
  4. composer 卡片反向：bg-surface → bg-field + border-line；textarea 去掉 !bg-field 改回透明； 加 focus-within:border-accent； textarea 自身的 focus:ring-0。
  5. 水位圆环去数字：14px → 16px，常态不渲染文字， 仅 hover 与 ≥90% 时出百分比； 阈值颜色沿用 fg-2 → warn → danger。
  6. 加模型选择器（T-201）：24px 高芯片 + flex-1 左侧定位； 弹层 w-72 以内、side="top"、复用 AgentDropdown；流式期间锁定。 → 本票唯一功能新增，可最后做。
第 1 步与第 2~6 步之间建议断一次：第 1 步修的是上一轮遗留的观感回归， 单独验收能立刻看出「白卡浮在深壳上」有没有消失； 第 2~6 步是新的重排，混在一起会看不清是哪一步带来的变化。
