改动方案与落点

A 文案零风险，必做
  • src/locales/zh/newtab.json:775-776 与 en 同步：pickTab.auto「自动」→「跟随当前页」；pickTab.pinned「固定」→「已固定」。
  • 只动文案，不改逻辑；两宿主同时生效。
B tooltip零风险
  • AgentTabPicker.vue:39-49 徽标 span 加 :title：auto=「助手自动选当前页」/ pinned=「你已锁定此页，点开可解除」。
  • 当前整行只有 pickTab.title（「选择目标页」）一个 title，不解释 auto 含义。
C 样式零风险
  • auto 维持中性灰、pinned 改 accent 高亮（当前两态同色 bg-gray-500/15，看不出区别）。
  • 让「已固定」这一用户主动意图更显眼。
D 解除固定有逻辑，需评审
  • 根因：AgentTabList.vue 点选即 onPickTab→targetPinned=true，且无退回 auto 的路径——手选后永久 pinned（pin 跨轮持久化于会话 pins，见 targetState.js 的 initialPinsFromTab/upsertPin）。
  • 改动：下拉加「解除固定 / 跟随当前页」项 → host.unpin() 置 targetPinned=false。安全由 CONTEXT「resolveTargetTab 永远解析出一个页」保证。
  • 代价：新增 host 方法 + runtime 清 pins 接口，牵连会话持久化——单独评审，不在本设计稿直接落地。
建议落地顺序：先做 A+B+C（纯 i18n + UI，零逻辑风险，一轮可落地并补测试）； D 作为独立票评审。T-151（独立页 placeholder）已实测纠正——独立页也有 targetTab，原「误导」前提不成立，建议驳回或降级为可选软优化。
