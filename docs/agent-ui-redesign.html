基于真实代码的评价

上一版设计稿把截图误读成「通用网页助手产品」，脑补了「重新抓取 / 类比标签 / 抓取按钮」——前提错了，已作废。 本版严格对应 AgentPanel.vue。截图里的卡片排版全是 LLM 生成的 markdown，UI 只是渲染器。

当前 UI 已做对的地方

  • ✓ 确认门放文档流而非浮层（T-06）：不盖住输入区，翻历史也不悬着。
  • ✓ 目标页 chip 贴在输入区顶上：正是「我正要问这页」的决策点，参考 Cursor/VSCode。
  • ✓ 目标页失效显式化（T-08）：页关掉/origin 漂移不假装正常，红色 stale + 重新选择。
  • ✓ 工具状态不止靠颜色（T-13）：✓/✕/⊗ 形状不同，色觉障碍也能分。
  • ✓ 错误独立成类、可重试可复制详情（T-04），权重高于善意提醒。
  • ✓ 面板卸载时拒掉确认门（T-02），避免 loop 永久挂起、表现像卡死。

我建议的改进（均读代码推断，未实测用户反馈）

  • ① 「自动」徽标对非技术用户费解：它指 targetTab 解析模式（auto=运行时自动选 / pinned=用户固定），普通用户看不懂。建议 hover tooltip 已加（本稿），或文案改为「跟随当前页 / 已固定」。
  • ② placeholder 两宿主共用：独立助手页（Agent.vue）没有画布、无「这页」概念，却也显示「问问这个页面」。建议按宿主区分：侧栏用「问问这个页面」，独立页用「问我任何事」。
  • ③ 窄侧栏表格体验：markdown 表格靠 overflow-x-auto 横滑，320px 宽时可读性差。可在长表格上加「可横向滑动」微提示，或 agent 输出约定里建议窄表拆分。
  • ④ 会话 chip 信息密度：下拉里塞了模型名+上下文水位，窄侧栏 w-72 可能溢出，值来自 host.config。建议实测超长模型名时的截断。
