做法代价

bruntime 加真正的 clearContext（截断消息历史）动 agent 内核 + 持久化 + 压缩模块，需单独评审

输入框形态（待你拍板 ③）

你稿里的输入框是单行 pill（左侧还有一枚「+」）。两点直说：

① 单行化与 T-12 相抵：当初从 rows="3" 改成 autoresize，就是因为「写长指令只能在小窗里滚」。单行 pill 输入长文本体验更差，我建议保留 autoresize 多行（min-h 68 / max-h 128 不动），只把边框圆角与内边距调成你稿子的观感——形态上像 pill，行为上仍是多行。

② 左侧「+」语义不明：新建会话（header 已有）？附件（项目没有此能力）？默认不做，你定。
