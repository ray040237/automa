为什么这版比上一稿更站得住

1编辑卡那条我上次记反了

上一稿把「编辑卡打开时 tab 被盖住」记成缺点。它其实是这个方案的关键收益。

✗ 入口在顶栏 ⇒ 点它必须处理「正在编辑的块怎么办」：关掉（现在的坏行为，T-179）还是拒绝点击。
✓ 入口在侧栏内 ⇒ 编辑卡期间那行 tab 不渲染（v-if，不是层叠压住），物理上点不到。不用写任何防御代码，T-179 的两难自动消失。

2可发现性反过来了

新做的 AI 功能，藏成一个没文字的图标，发现率是最低的。

✗ 上一稿：顶栏一个无文字图标，得 hover 才知道是助手。
✓ 这版：一进工作流就看得见「块 | 助手」并排在侧栏顶上，字面写着，不用猜。

3论证终于自洽了

上一稿给 T-180 写的理由是「顶栏只管画布区域」，却把两个管侧栏的控件塞进了顶栏。

✓ 顶栏只剩折叠键（侧栏在不在）和两个 tab（画布区域看什么）； 侧栏里的 tab 管侧栏里是什么。三件事三个地方，互不越界。

已实施（2026-10-09）： [id].vue 侧栏顶部新增 SIDEBAR_TABS 那行 tab；顶栏按钮与其 toggleAgentPanel 整个删除；sidebarPanel 默认值由 details 改为 blocks；新增 workflow.agent.sidebarBlocks（zh/en）。守卫见 panelUi.test.js，6 条。
