4 · 交互细节，先把坑说死

话题 规则
@ 的触发 光标前一个字符是行首或空格时才触发。选中后消费掉这个 token （把 @查询词 从 draft 里删掉）+ 把该页设为 pinned —— 这跟 / 不同：/ 是整框替换成模板正文， @ 是「改目标页」这个副作用。
与 / 互斥 / 优先。它是「整框以 / 开头」的整框态，语义比词内 @ 强；且 / 菜单里第一项就是命令，用户看到的是命令列表而不是 tab 列表。
中文输入法 真实的坑 中文输入法下 @ 常处于候选组词状态。菜单要等 compositionend（或用 e.isComposing 直接跳过） 再判定，否则打字过程中菜单会闪。
X 解除 只在 pinned 时渲染。点击 → host 把该 tabId 从 pins 移除、清 focusedTabId；tab.js 的降级链 （pinned → lastAccessed → 当前窗口 → 其他窗口）已经覆盖「pinned 不存在」的情况，chip 不会闪空。
chip 标题截断 320px 下：favicon 16 + gap 6 + 标题 + badge（自动/固定 约 30）+ X（仅 pinned 16）+ padding 8 → 标题约 180px ≈ 15 个中文字（12px）。 落地时按实测调，别让 badge 被挤掉 —— badge 是这行唯一说清「这是不是你选的」的东西。
失效态 state 为 closed / drift 时，chip 行整体转红底 + 「目标页已关闭」+「重新选择」（与现在一致），X 隐藏 —— 这时候该做的是重选，不是解除。
忙碌态 底行发送键换成 ■ 停止；chip 仍可点（换目标页不影响正在跑的那一轮， 和现在一致）；水位明细里的「新会话」照旧 disabled。
